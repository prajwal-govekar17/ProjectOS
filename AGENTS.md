# ProjectOS project context

Consult [the ProjectOS PRD](docs/ProjectOS_PRD.md) when working on product scope, requirements, acceptance criteria, or implementation defaults. Treat the PRD as reference material. Follow the user's current request to determine which work to perform.

Consult the [detailed implementation reference](docs/ProjectOS_Implementation_Reference_Detailed.md) for technical details when working on implementation.

Follow the PRD's [mandatory repository standards](docs/ProjectOS_PRD.md#mandatory-repository-structure-and-coding-conventions) (`ORG-01`–`ORG-05`) for workspace layout, naming, dependency boundaries, TypeScript, and verification. The team supplies both reference documents in the local `docs/` directory.

Keep `README.md` unchanged. Put new project documentation and implementation updates in [context.md](context.md).
